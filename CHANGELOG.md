# Changelog


## v1.2.0

[compare changes](https://github.com/evenfrost/react-inline-css-module/compare/v1.1.0...v1.2.0)

### 🚀 Enhancements

- Add `attributeNames` option to support arbitrary `*StyleName` props mapped to class props
- Fold custom target class props into `className` on intrinsic elements to avoid React DOM warnings
- Provide runnable custom-attribute example (Vite) and document usage

### 🧪 Tests

- Add Vitest suite covering transform wiring and runtime class merging

### 🏡 Chore

- Add example dev/build scripts and React/Vite React dev dependencies
- Improve README with options, examples, and scripts
